## Принципы выбора приложения из кластера

Мини-агент использует следующие критерии:

1. **Размер компании**
   - <10 человек → простые решения
   - 10-50 → SMB решения
   - 50-200 → SMB/Enterprise решения
   - 200+ → Enterprise решения

2. **Бюджет**
   - Tight budget → Free tier или недорогие
   - Medium budget → Mid-tier
   - Large budget → Premium features

3. **Технические требования**
   - Non-technical → No-code, easy UI
   - Technical → API-rich, customizable

4. **Интеграции**
   - Существующий стек
   - Обязательные интеграции

5. **Индустрия**
   - Специфичные для индустрии фичи
   - Compliance requirements
