# Глоссарий терминов INFO5

Словарь ключевых терминов и концепций, используемых в проекте INFO5.

---

## A

### Agent (Агент)
Автономная программная сущность, способная выполнять задачи от имени пользователя. В INFO5 существуют два типа:
- **Big AI Agents** (Уровень 1): Общие AI модели типа GPT-4
- **Mini-Agents** (Уровень 2): Специализированные агенты-эксперты

См. также: [Mini-Agent](#mini-agent)

### Agent Orchestrator (Оркестратор агентов)
Компонент Уровня 1, который координирует работу множества мини-агентов при выполнении сложных задач, требующих участия нескольких агентов.

### AI-native
Приложение или сервис, разработанный с учетом интеграции с AI-системами. Предоставляет structured data и APIs, удобные для AI.

### API (Application Programming Interface)
Набор правил и протоколов, позволяющих приложениям взаимодействовать друг с другом программно. INFO5 использует APIs для управления приложениями.

### Automation (Автоматизация)
Процесс выполнения задач без участия человека. В INFO5: интеллектуальная автоматизация с использованием AI.

---

## B

### Best Practices (Лучшие практики)
Проверенные методы и подходы для выполнения задач. Мини-агенты INFO5 имеют встроенные best practices для своих областей.

### Business Process Automation (BPA)
Автоматизация повторяющихся бизнес-процессов. INFO5 специализируется на BPA для офисной работы.

---

## C

### Cluster (Кластер)
**Уровень 3 архитектуры INFO5.** Логическая группа приложений, объединенных по общим признакам (функция, отрасль, процесс).

**Пример:** Кластер "SMB Email Marketing" включает Mailchimp, ConvertKit, Sendinblue и др.

**Структура:**
```
Супер-категория (15-20)
└─ Мета-категория (80-100)
   └─ Кластер (200-300)
      └─ Приложения (15-40 на кластер)
```

См. также: [Clustering](#clustering)

### Clustering (Кластеризация)
Процесс организации тысяч приложений в логические группы (кластеры). Методология Уровня 3.

**Цели:**
- Снижение сложности (5000 apps → 200-300 кластеров)
- Упрощение навигации
- Основа для специализации агентов

См.: [Методология кластеризации](/docs/methodology/level-3-clustering.md)

### CrewAI
Open-source фреймворк для создания команд AI-агентов с определенными ролями. Используется INFO5 для реализации мини-агентов.

---

## D

### Delegation (Делегирование)
Передача задачи от Уровня 1 (AI Orchestrator) специализированному мини-агенту Уровня 2.

**Процесс:**
1. Пользователь → Запрос
2. AI анализирует → Определяет область
3. AI делегирует → Подходящему агенту
4. Агент выполняет → Возвращает результат

### Domain Expert (Доменный эксперт)
Тип мини-агента, специализирующийся в конкретной области бизнеса (CRM, email marketing, accounting и т.д.).

**Характеристики:**
- Глубокое знание 1-3 кластеров
- Понимание best practices
- Типичные use cases
- Troubleshooting expertise

**Примеры:**
- MA-001: Team Communication Expert
- MA-015: CRM Setup Expert
- MA-025: Email Marketing Expert

---

## E

### Escalation (Эскалация)
Передача задачи на более высокий уровень, когда мини-агент не может справиться самостоятельно.

**Путь эскалации:**
Мини-агент (L2) → AI Orchestrator (L1) → Человек

---

## F

### Four Levels (Четыре уровня)
Основная архитектура INFO5:

```
Уровень 1: ИИ/Нейросети (GPT-4, Claude 3)
Уровень 2: Мини-агенты (200-300 специалистов)
Уровень 3: Кластеры (200-300 групп)
Уровень 4: Приложения (5000+)
```

См.: [Архитектура четырех уровней](/docs/architecture/four-levels.md)

---

## H

### Human-in-the-Loop (HITL)
Подход, при котором критичные решения требуют одобрения человека перед выполнением.

**В INFO5 требует HITL:**
- Финансовые транзакции
- Удаление данных
- Изменение security settings
- Первый запуск нового automation

---

## I

### Integration (Интеграция)
Соединение двух или более приложений для обмена данными и автоматизации процессов.

**Типы в INFO5:**
- **Direct API:** Прямое подключение через API
- **iPaaS:** Через Make.com/Zapier
- **RPA:** Имитация действий пользователя (fallback)

### Integration Platform as a Service (iPaaS)
Платформа для соединения приложений (Zapier, Make.com). INFO5 использует iPaaS как Уровень 4.

---

## K

### Knowledge Base (База знаний)
Хранилище информации мини-агента о его области:
- Документация приложений
- Best practices
- Типичные проблемы и решения
- Use cases

---

## L

### LangChain
Open-source фреймворк для создания AI-приложений с использованием LLM. Используется в INFO5 для Уровней 1 и 2.

### Large Language Model (LLM)
Большая языковая модель (GPT-4, Claude 3, и др.). Используется на Уровне 1 для понимания запросов и планирования.

### Level 1 / Уровень 1
**ИИ и большие нейросети.** Вершина пирамиды INFO5.

**Функции:**
- Понимание запросов пользователя
- Стратегическое планирование
- Делегирование мини-агентам
- Синтез результатов

**Технологии:** GPT-4, Claude 3.5, LangChain

### Level 2 / Уровень 2
**Мини-агенты.** Специализированные AI-агенты.

**Функции:**
- Экспертное знание области
- Выбор и настройка приложений
- Автоматизация задач
- Troubleshooting

**Количество:** 200-310 агентов

См.: [Методология мини-агентов](/docs/methodology/level-2-mini-agents.md)

### Level 3 / Уровень 3
**Кластеры приложений.** Организованные группы приложений.

**Функции:**
- Организация тысяч приложений
- Упрощение навигации
- Основа для специализации агентов

**Количество:** 200-300 кластеров

См.: [Методология кластеризации](/docs/methodology/level-3-clustering.md)

### Level 4 / Уровень 4
**Приложения.** Основание пирамиды - тысячи SaaS приложений.

**Примеры:**
- Make.com (~2000 apps)
- Zapier (~7000 apps)
- Direct integrations (top 100 apps)

**Функции:**
- Выполнение конкретных задач
- Хранение данных
- Интеграции

## M

### Meta-Category (Мета-категория)
Средний уровень в иерархии кластеризации:
```
Супер-категория
└─ Мета-категория ← Здесь
   └─ Кластер
```

**Пример:**
- Супер-категория: "Marketing and Advertising"
- Мета-категория: "Email Marketing"
- Кластеры: SMB Email, Enterprise Email, E-commerce Email

**Количество:** 80-100 мета-категорий

### Mini-Agent (Мини-агент)
**Ключевая концепция Уровня 2.** Специализированный AI-агент, эксперт в узкой области.

**Характеристики:**
- Область знаний: Узкая, специализированная
- Глубина знаний: Глубокая в своей области
- Управляет: 1-3 кластерами приложений
- Автономность: Высокая

**Типы:**
1. Domain Expert Agents (100-150)
2. Process Automation Agents (50-80)
3. Integration Specialist Agents (30-50)
4. Troubleshooting Agents (20-30)

**Пример структуры:**
```yaml
mini_agent_id: "MA-015"
name: "SMB CRM Setup Expert"
responsibility:
  primary_cluster: "L3-030-SMB-SALES-CRM"

applications_knowledge:
  expert_in:
    - HubSpot CRM (98% знание)
    - Pipedrive (95%)
    - Zoho CRM (90%)
```

См.: [Примеры агентов](/levels/level-2-agents-examples.md)

---

## N

### No-Code / Low-Code
Подход к созданию приложений и автоматизации с минимальным или нулевым кодированием.

INFO5 - no-code solution для большинства пользователей, с low-code опциями для продвинутых.

---

## O

### OAuth 2.0
Протокол авторизации, используемый для безопасного подключения к приложениям без раскрытия паролей.

### Orchestration (Оркестрация)
Координация множества агентов и сервисов для выполнения сложной задачи.

**В INFO5:**
- AI Orchestrator (Level 1) координирует Mini-Agents (Level 2)
- Parallel execution когда возможно
- Sequential когда есть зависимости

---

## P

### Playbook
Пошаговая инструкция для выполнения типичной задачи. Мини-агенты используют playbooks как базу знаний.

**Пример playbook:**
```yaml
task: "Setup CRM for startup"
steps:
  1. Assess needs (size, budget, industry)
  2. Recommend platform
  3. Create account
  4. Configure pipeline
  5. Import data
  6. Setup integrations
  7. Train team
```

### Process Automation Agent
Тип мини-агента, специализирующийся на автоматизации конкретных бизнес-процессов.

**Примеры:**
- Invoice Processing
- Onboarding Automation
- Lead Qualification
- Report Generation

---

## R

### RPA (Robotic Process Automation)
Технология автоматизации через имитацию действий пользователя в UI.

**В INFO5:** Используется как fallback когда нет API или интеграции.

### ROI (Return on Investment)
Возврат инвестиций. Для INFO5 типично: 20-50x ROI в первые 3 месяца.

---

## S

### SaaS (Software as a Service)
Модель поставки ПО как облачного сервиса. Большинство приложений Уровня 4 - SaaS.

### Specialization (Специализация)
Ключевой принцип INFO5: Вместо одного универсального AI - множество специализированных агентов.

**Преимущества:**
- Глубокое знание области
- Выше качество результата
- Быстрее выполнение
- Надежнее работа

### Super-Category (Супер-категория)
Верхний уровень в иерархии кластеризации:
```
Супер-категория ← Здесь
└─ Мета-категория
   └─ Кластер
```

**Примеры:**
1. Коммуникация и Collaboration
2. CRM и управление клиентами
3. Маркетинг и реклама
4. Финансы и бухгалтерия
5. Управление проектами
... (всего 15-20)

---

## T

### Task (Задача)
Единица работы, выполняемая агентом. В INFO5 измеряется в "tasks per month" для pricing.

**Примеры задач:**
- Setup email marketing campaign
- Create invoice
- Import contacts to CRM
- Generate report

### Taxonomy (Таксономия)
Иерархическая классификационная система. В INFO5: таксономия приложений Уровня 3.

```
Супер-категория (15-20)
└─ Мета-категория (80-100)
   └─ Кластер (200-300)
      └─ Приложение (5000+)
```

### Tool (Инструмент)
В контексте AI: внешняя функция или API, которую может вызвать агент.

В контексте бизнеса: приложение для выполнения задач (синоним "app").

---

## U

### Use Case (Сценарий использования)
Описание конкретной практической задачи и способа её решения с помощью INFO5.

**Примеры:**
- Стартап setup с нуля
- E-commerce marketing automation
- Agency operations automation

См.: [Use Cases](/examples/use-cases.md)

---

## W

### Webhook
Механизм для получения автоматических уведомлений о событиях в приложении. Используется для real-time интеграций.

### Workflow
Последовательность шагов для выполнения процесса. В INFO5: автоматизированные workflows создаются и выполняются агентами.

**Типы:**
- Sequential: Шаги выполняются по порядку
- Parallel: Несколько шагов одновременно
- Conditional: Ветвление на основе условий

---

## Z

### Zero-touch Automation
Полностью автоматизированный процесс, не требующий вмешательства человека.

**Vision INFO5 (2030+):** Большинство рутинных задач станут zero-touch.
